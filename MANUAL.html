🚀 快速開始

1. 加入小組成員

在「成員與技能」區域輸入成員姓名，按下 新增成員。

如果希望限制某位成員一週最多服事幾次，也可以設定「每週最多 N 次」。

2. 設定每個人的服事項目

加入成員後，勾選每個人可以負責的服事。

預設包含：

  • 信息
  • 敬拜
  • 破冰
  • 點心

如果小組有其他服事，例如「招待」、「攝影」、「場地」等，也可以使用 新增技能 自行增加。

3. 設定聚會日期

在「聚會設定」中設定：

  • 起始日
  • 結束日
  • 每週聚會日

例如：

10/1 ～ 12/31 每週五聚會

系統就會依照這個期間產生每週的服事表。

4. 設定無法出席的日期

如果某位成員某天請假、出差或無法參加聚會：

  1. 在該成員的「不可出席」欄選擇日期
  2. 按下 加入
  3. 系統自動排班時就會避開該日期

如果之後行程有變，也可以直接把日期移除。

5. 設定休息日

遇到連假、特別聚會或小組暫停時，可以把該日期加入 休息日期。

休息日不會安排任何服事。

✨ 自動排班

資料設定完成後，按下：

「自動排班」

系統會依照每個人的：

  • 可服事項目
  • 不可出席日期
  • 每週服事上限
  • 各角色已服事次數
  • 總服事次數
  • 最近是否已經服事
  • 是否連續幾週服事

自動安排一份盡量平均的服事表。

💡 自動排班是協助小組長快速產生初稿，不代表一定要照表使用，排完後仍然可以手動調整。

✏️ 手動調整

自動排班完成後，每個服事項目都可以直接從下拉選單更換人員。

如果同一個人在同一天被安排了多個服事，系統會顯示提醒，但不會強制禁止。

因此遇到特殊聚會時，小組長仍然可以自由安排。

📊 查看服事統計

下方的「統計表」會統計每位成員：

  • 各項服事的次數
  • 總服事次數

可以快速確認服事是否過度集中在少數人身上。

📥 匯出 Excel

排班完成後，按下：

「匯出 Excel」

即可下載服事表，方便：

  • 傳到小組群組
  • 放到 Google Drive
  • 再自行編輯或美化
  • 列印服事表

💾 備份與換電腦

平常的設定會自動保存在目前使用的瀏覽器中。

如果要換電腦、換瀏覽器，或希望保留一份備份，建議使用：

「匯出設定 (JSON)」

把設定檔保存起來。

下次開啟工具後，按：

「匯入設定 (JSON)」

就可以把成員、技能、不可出席日期與聚會設定載入回來。

⚠️ 建議重要資料定期匯出 JSON 備份。瀏覽器資料被清除後，本機儲存的設定也可能消失。

💡 建議使用流程

加入成員 → 勾選每個人的服事項目 → 填寫不可出席日期 → 設定聚會期間與聚會日 → 加入休息日期 → 自動排班 → 手動微調 → 確認統計 → 匯出 Excel

完成 🎉

❤️ 關於這個工具

這個工具的目的不是取代同工之間的溝通，而是減少小組長每次排班時重複計算與整理的時間。

希望讓排班簡單一點，把更多時間留給人、關係與服事。

如果你覺得這個工具對其他小組也有幫助，歡迎把網址分享給有需要的小組長 🙌
